Version 1.0.0 - The Grand Release

The initial stable release of PMA Recipe Book. This version establishes the core architecture and introduces the unique "Tin" interface.

  • Feature: Implemented the "Tin" Rolodex-style scrolling interface.
  • Feature: Added Volume Key navigation for hands-free control.
  • Feature: Launched the Flavor Engine with initial vector mapping for 500+ ingredients.
  • Feature: Integrated the Boutique Theme Engine (Crema, Charcoal, Cobalt, Jade).
  • System: Implemented strict English/French localization with correct typography rules.
  • System: Established the Relational Culinary Database.
  • Bug Fix: Resolved layout clipping on small-screen devices.

Version 0.9.0 - Public Beta

The public beta release allowed for community testing of the substitution engine and scaling features.

  • Feature: Added Cosine Similarity calculation for ingredient substitutions.
  • Feature: Implemented Volumetric-to-Mass conversion database.
  • Feature: Added "Usage Tallies" to track recipe frequency.
  • Improvement: Optimized database queries for faster search results.
  • Improvement: Refined the "Fraction Formatter" to display fractions like 1/2 instead of 0.5.
  • Bug Fix: Fixed an issue where specific French characters caused text overflow in the sidebar.

Version 0.8.0 - Alpha Testing

Internal alpha testing focused on the core data models and the Theme Engine.

  • Feature: Initial implementation of the Domain-Driven Data Models.
  • Feature: Created the portable Boutique Theme Engine.
  • Feature: Added basic Recipe CRUD (Create, Read, Update, Delete) functionality.
  • System: Migrated theme engine to neutral package namespace for portability.
  • Refactor: Decoupled the Root Activity to act strictly as a thin orchestrator.
